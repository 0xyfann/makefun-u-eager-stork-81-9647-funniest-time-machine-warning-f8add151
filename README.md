A one-line warning label for a time machine, written to get the biggest laugh from a room of time travellers, for the make.fun competition "Funniest Time Machine Warning".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> WARNING: If you meet yourself in the past, do not wave. He knows what you did.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
